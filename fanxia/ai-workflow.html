3.1 Make Components AI-Readable

Upgrade visual assets into searchable, composable, constrained design knowledge.

01 | Templates

Build page and overlay templates from components, so AI reuses proven structures.

02 | Semantic Naming

Business-aligned names let AI pull components straight from brief keywords.

03 | States as Variants

Size, state, and mode live in properties, so AI retrieves the exact component and state.

04 | Usage Rules

Guidelines tell AI when a component can—and cannot—be used.

05 | One Library

Publish one library and sync names, versions, and states—no stale duplicates.

Keep components reliably accessible, reusable, and updatable for teams and AI.

Four Areas of Internal Skill Optimization

1. Trigger + Boundaries

Define when to call a Skill, when not to, and what it owns.

2. Process + Intermediate Outputs

Standardize each stage's input, process, and output so failures can be traced.

3. Output + Acceptance

Every step delivers an output plus clear acceptance criteria.

4. Testing + Iteration

Test on real, similar cases—designers test too, not only AI.

More precise calls, less context, more stable results, faster testing, and higher output efficiency.
