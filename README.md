# Fan Xia — Portfolio

Public portfolio for https://fanx07.github.io/.

## Publish

Create the public repository `FanX07.github.io` under the account `FanX07`.
Upload the contents of this folder directly to the repository root, including `assets/` and `.nojekyll`.
In Settings → Pages, select Deploy from a branch, branch `main`, folder `/ (root)`, then Save.

## Edit

- `index.html`: welcome screen.
- `copy-of-work.html`: Work gallery.
- `netease-game-ai-saas-workflow.html`: Netease project.
- `eufymake-uv-printer-20-optimization.html`: eufyMake project.
- `work.html`: Play gallery.
- `resume-1.html`: Resume.
- `drawing-1.html`: Drawing.

Add new images to `assets/` and reference them in the corresponding HTML page. Commit changes to `main` to trigger GitHub Pages publication.
